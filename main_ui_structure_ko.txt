DRAME main UI 구조 설명
=======================

이 문서는 lib/feat/main/ui 폴더가 어떤 역할을 하는지, 그리고 홈 화면에서 보이는 각 영역이
어떤 코드와 연결되는지 정리한 파일입니다.


1. 전체 폴더 구조
-----------------

lib/feat/main/ui
├── pages
│   └── main_page.dart
└── component
    ├── main_component.dart
    └── operator_mypage_component.dart


핵심 파일은 main_page.dart입니다.

main_page.dart는 홈 화면의 진입점, 상태 관리, 화면의 큰 흐름을 담당합니다.
component 폴더의 두 파일은 main_page.dart에 part로 연결되어 있어서, 독립 파일이라기보다는
main_page.dart의 일부처럼 동작합니다.

main_page.dart 안에는 아래 코드가 있습니다.

part '../component/main_component.dart';
part '../component/operator_mypage_component.dart';

이 때문에 main_component.dart와 operator_mypage_component.dart 안의 private 클래스들도
main_page.dart 안에서 바로 사용할 수 있습니다.


2. main_page.dart의 역할
-----------------------

파일 위치:
lib/feat/main/ui/pages/main_page.dart

이 파일은 main UI의 중심입니다.

담당하는 것:
- 홈 화면의 전체 구조
- 이용자 모드와 운용자 모드 전환
- DrameStore 상태 관리
- 홈 상단 히어로 영역
- 운용자 등록, 운용자 마이페이지, 요청 검토 화면의 진입점
- component 파일들을 part로 묶는 역할


주요 구성 요소:

HomeText
- 홈 화면 전용 텍스트 스타일 모음입니다.
- 로고, 히어로 제목, 히어로 보조 문구, 상단 버튼 스타일 등을 정의합니다.

색상 상수
- _navy: 주요 남색
- _ink: 진한 텍스트 색상
- _muted: 보조 텍스트 색상
- _soft: 연한 배경색
- _line: 경계선 색상
- _mint: 강조용 초록색

PilotDroneForm
- 운용자 등록 과정에서 드론 1대의 입력 상태를 담습니다.

PilotOnboardingData
- 운용자 온보딩 전체 입력값을 담는 화면 상태입니다.

OperatorFeedPost
- 운용자 마이페이지 피드에 올리는 게시글 화면 모델입니다.

PilotWorkRequest
- 운용자가 받은 작업 요청을 화면에 보여주기 위한 샘플 모델입니다.

DrameStore
- ChangeNotifier 기반의 상태 관리 클래스입니다.
- 선택된 카테고리, 선택된 지역, 운용자 모드 여부, 로그인/온보딩 상태 등을 관리합니다.

DrameHomePage
- '/' 라우트에서 처음 보이는 홈 페이지입니다.
- 이용자 모드와 운용자 모드를 같은 화면 안에서 상태에 따라 바꿔 보여줍니다.


3. 홈 화면의 큰 흐름
-------------------

홈 화면은 DrameHomePage의 build 함수 안에서 구성됩니다.

대략적인 구조:

CustomScrollView
├── DrameTopNavigation
├── DrameSecondaryNavigation
├── 이용자 모드 화면 또는 운용자 모드 화면
└── Footer


3-1. 공통 상단 영역

DrameTopNavigation
- 최상단 로고, 이용자/운용자 모드 전환, 로그인/회원가입, 운용자 등록 버튼을 담당합니다.
- 실제 코드는 lib/common/drame_navigation.dart에 있습니다.

DrameSecondaryNavigation
- 촬영자 찾기, 포트폴리오, 요청 검토, 마이페이지 같은 보조 메뉴를 담당합니다.
- 버튼을 누르면 특정 섹션으로 스크롤하거나 다른 화면으로 이동합니다.


3-2. 이용자 모드 화면 순서

이용자 모드에서는 아래 순서로 화면이 구성됩니다.

1. _LandingHeroSection
2. _CategorySelectionSection
3. _AreaSelectionSection
4. _OperatorListSection
5. DroneFeedSection
6. _PopularPortfolioSection
7. _FooterSection


_LandingHeroSection
- 홈페이지 최상단의 짙은 남색 배경 영역입니다.
- 흔히 "히어로 영역"이라고 부릅니다.
- 화면에서 가장 먼저 서비스의 핵심 문구를 보여주는 대표 영역입니다.
- 현재 화면에서는 "필요한 드론 작업, 검증된 조종사와 빠르게 연결하세요" 문구가 있는 부분입니다.

_CategorySelectionSection
- 히어로 다음에 나오는 첫 선택 영역입니다.
- 이용자가 필요한 드론 작업 종류를 고릅니다.
- 예: 항공촬영, 농약방제, 부동산, 측량·매핑, 시설점검, 행사촬영
- 선택된 카테고리는 DrameStore에 저장됩니다.

_AreaSelectionSection
- 카테고리를 선택한 뒤 촬영 지역을 고르는 섹션입니다.
- 카테고리를 고르기 전에는 보이지 않습니다.

_OperatorListSection
- 선택된 카테고리와 지역 조건에 맞는 운용자 카드를 보여줍니다.
- 운용자 카드를 클릭하면 해당 운용자의 포트폴리오 페이지로 이동합니다.

DroneFeedSection
- 드론 관련 피드 영역입니다.
- 실제 코드는 feed 기능 쪽에 있습니다.

_PopularPortfolioSection
- 홈페이지 하단의 인기 포트폴리오 섹션입니다.
- 카테고리 칩을 선택하면 해당 작업 유형을 가진 운용자만 필터링합니다.

_FooterSection
- 홈과 운용자 화면 맨 아래에 반복되는 푸터입니다.


3-3. 운용자 모드 화면 순서

운용자 모드에서는 상태에 따라 아래 화면 중 하나가 표시됩니다.

1. _PilotLandingSection
2. _PilotAuthSection
3. _PilotOnboardingSection
4. _PilotDashboardSection


_PilotLandingSection
- 운용자 모드에서 로그인/등록 전 처음 보이는 소개 섹션입니다.

_PilotAuthSection
- 운용자 로그인과 회원가입 입력 폼을 담당합니다.

_PilotOnboardingSection
- 운용자 등록 절차 전체를 단계별 카드로 구성합니다.
- 면허, 사업자 정보, 보험, 드론 정보, 활동 지역 등을 입력하는 흐름입니다.

_PilotDashboardSection
- 운용자 등록이 끝난 뒤 보이는 대시보드 요약 섹션입니다.


4. main_component.dart의 역할
----------------------------

파일 위치:
lib/feat/main/ui/component/main_component.dart

이 파일은 홈 화면과 운용자 화면에서 쓰는 대부분의 실제 UI 조각을 담고 있습니다.

담당하는 것:
- 카테고리 선택 UI
- 지역 선택 UI
- 운용자 목록 카드
- 운용자 랜딩/로그인/온보딩/대시보드
- 요청 검토 화면
- 포트폴리오 카드
- 공통 섹션 레이아웃
- 푸터


주요 구성 요소:

AppText
- 홈과 운용자 화면에서 공유하는 텍스트 스타일입니다.
- HomeText보다 더 작은 카드, 섹션, 버튼 단위 스타일을 담당합니다.

_CategorySelectionSection
- 이용자가 필요한 드론 작업 종류를 고르는 섹션입니다.
- 선택된 카테고리는 DrameStore에 저장되고, 이후 지역 선택과 운용자 목록 노출 조건이 됩니다.

_ServiceCategoryCard
- 카테고리 하나를 나타내는 선택 카드입니다.
- 선택 여부에 따라 배경과 글자 색을 바꿔 현재 선택 상태를 보여줍니다.

_AreaSelectionSection
- 카테고리를 선택한 뒤 촬영 지역을 고르는 섹션입니다.
- 연한 회색 배경을 사용해 카테고리 영역과 운용자 목록 사이를 구분합니다.

_OperatorListSection
- 선택된 조건에 맞는 운용자 카드를 그리드로 보여주는 섹션입니다.

_OperatorMatchCard
- 검색 결과에 표시되는 운용자 카드입니다.
- 클릭하면 해당 운용자의 포트폴리오 페이지로 이동합니다.

_PilotLandingSection
- 운용자 모드에서 로그인/등록 전 처음 보이는 소개 섹션입니다.

_PilotAuthSection
- 운용자 로그인과 회원가입 입력 폼을 담당합니다.

_PilotDashboardSection
- 운용자 등록이 끝난 뒤 보이는 대시보드 요약 섹션입니다.

_PilotRequestReviewPage
- 운용자가 들어온 작업 요청을 검토하고 견적을 입력하는 화면입니다.

_PilotOnboardingSection
- 운용자 등록 절차 전체를 단계별 카드로 구성하는 섹션입니다.

_PopularPortfolioSection
- 홈페이지 하단의 인기 포트폴리오 섹션입니다.
- 카테고리 칩을 선택하면 해당 작업 유형을 가진 운용자만 필터링합니다.

_PageShell
- 모든 주요 섹션의 최대 너비와 좌우 여백을 통일하는 레이아웃 래퍼입니다.
- 섹션마다 같은 폭과 여백을 유지하려고 사용합니다.

_SectionHeader
- 섹션 상단의 보조 문구, 제목, 우측 액션 텍스트를 공통으로 그립니다.

_FooterSection
- 홈과 운용자 화면 맨 아래에 반복되는 푸터입니다.


5. operator_mypage_component.dart의 역할
---------------------------------------

파일 위치:
lib/feat/main/ui/component/operator_mypage_component.dart

이 파일은 운용자 마이페이지 전용 UI를 담당합니다.

담당하는 것:
- 운용자 마이페이지 전체 화면
- 프로필 카드
- 등록 정보 수정 UI
- 드론 목록
- 운용자 피드 작성/삭제


주요 구성 요소:

_OperatorProfileManagementPage
- 운용자 마이페이지 전체 화면입니다.
- 상단 내비게이션, 프로필/등록 정보, 피드 관리, 푸터를 하나의 스크롤 화면으로 묶습니다.

_OperatorMyPageBody
- 마이페이지 본문 영역입니다.
- 화면 너비에 따라 프로필과 정보 카드를 1열 또는 2열로 배치합니다.

_OperatorMyPageProfile
- 운용자 이름, 닉네임, 인증 상태를 보여주는 프로필 카드입니다.

_OperatorInfoCard
- 등록 정보 묶음을 카드 형태로 보여주는 공통 컨테이너입니다.

_OperatorDroneListCard
- 운용자가 등록한 드론 목록과 기체별 작업 유형을 보여줍니다.

_InlineEditableText
- 마이페이지에서 텍스트 값을 바로 수정하는 작은 입력 행입니다.

_InlineEditableSelect
- 마이페이지에서 선택형 값을 바로 수정하는 드롭다운 행입니다.

_OperatorFeedSection
- 운용자가 자신의 작업 피드를 작성하고 목록을 관리하는 섹션입니다.

_FeedPostCard
- 운용자 피드에 표시되는 게시글 카드입니다.


6. 화면에서 코드 찾는 법
-----------------------

상단 로고, 로그인, 운용자 등록 버튼을 수정하고 싶다면:
lib/common/drame_navigation.dart

홈 화면 전체 순서를 수정하고 싶다면:
lib/feat/main/ui/pages/main_page.dart

홈 상단의 큰 남색 소개 영역을 수정하고 싶다면:
lib/feat/main/ui/pages/main_page.dart
_LandingHeroSection

카테고리별 드론 서비스 영역을 수정하고 싶다면:
lib/feat/main/ui/component/main_component.dart
_CategorySelectionSection
_ServiceCategoryCard

카테고리 선택 후 나오는 지역 선택 영역을 수정하고 싶다면:
lib/feat/main/ui/component/main_component.dart
_AreaSelectionSection
_AreaFilter

조건에 맞는 운용자 카드 목록을 수정하고 싶다면:
lib/feat/main/ui/component/main_component.dart
_OperatorListSection
_OperatorMatchCard

인기 포트폴리오 영역을 수정하고 싶다면:
lib/feat/main/ui/component/main_component.dart
_PopularPortfolioSection
_PilotPortfolioCard

운용자 로그인/회원가입 화면을 수정하고 싶다면:
lib/feat/main/ui/component/main_component.dart
_PilotAuthSection

운용자 등록 단계 화면을 수정하고 싶다면:
lib/feat/main/ui/component/main_component.dart
_PilotOnboardingSection

운용자 마이페이지를 수정하고 싶다면:
lib/feat/main/ui/component/operator_mypage_component.dart

8. 용어 정리
------------

히어로 영역
- 홈페이지 상단에서 가장 크게 보이는 대표 소개 영역입니다.
- 보통 서비스의 핵심 문구, 대표 이미지, 주요 CTA가 들어갑니다.
- 이 프로젝트에서는 짙은 남색 배경에 큰 문구가 있는 _LandingHeroSection이 히어로 영역입니다.

섹션
- 화면을 구성하는 큰 단위입니다.
- 예: 히어로 섹션, 카테고리 섹션, 지역 선택 섹션, 포트폴리오 섹션

카드
- 섹션 안에서 반복되는 작은 정보 단위입니다.
- 예: 카테고리 카드, 운용자 카드, 포트폴리오 카드

Store
- 화면 상태를 저장하고 변경을 알리는 객체입니다.
- 이 프로젝트에서는 DrameStore가 카테고리 선택, 운용자 모드, 로그인/온보딩 상태 등을 관리합니다.

part 파일
- Dart에서 한 파일을 여러 조각으로 나누어 작성하는 방식입니다.
- main_component.dart와 operator_mypage_component.dart는 main_page.dart의 part 파일입니다.
